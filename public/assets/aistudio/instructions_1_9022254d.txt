  2. Local MAD Scene-Cut Detector: Samples video at ~2.5 frames/sec, downscaled to 64px width; computes Mean Absolute Difference (MAD) across adjacent frame RGB values; dynamically sets threshold `avgMad + 0.75 * stdMad` to identify visual cut timestamps.
  3. Audio Beat Detector: Decodes audio stream into raw PCM FloatArray; computes RMS energy across 50ms windows; detects local peaks (>1.45x local average, min gap 0.25s).
  4. Storyboard Generator: Extracts a 5x5 grid (25 timestamped frame thumbnails).
  5. Anchor Keyframe Sheet: Generates a 4-column keyframe sheet specifically capturing visual cuts and detected beat peaks.
- Stage 1 Gemini Request:
  - Streams live thought tokens (`p.thought`) to the terminal.
  - Streams `[LOG]` lines describing every cut, panel layout, blur direction, and light-trail strand count.
  - Emits `===JSON_RESULT===`: JSON with `meta` (duration, aspect ratio, cuts, beats) and `timelineBlueprint`.
  - Emits `===CODE_RESULT===`: Helper tools implementing custom effects.
- Live Process Monitor: Shows spinning indicator, elapsed time, characters received, progress bar, and rolling log feed.

7. EXECUTION ENGINE SPECIFICATION: REPLACING JS `new Function()`
--------------------------------------------------------------------------------
To maintain 100% parity with the web version's ability to run AI-synthesized code:
- Embed `io.github.dokar3:quickjs-kt-android:1.0.15` as the execution bridge.
- Bind native host primitives to the JavaScript global `runtime` object:
  - `runtime.getCanvas(key, w, h)` -> Offscreen Bitmap / OpenGL FBO buffer.
  - `runtime.getFrame(media, t)` -> Extracts Bitmap at timestamp `t`.
  - `runtime.drawCover(ctx, media, x, y, w, h, zoom)` -> Aspect-safe draw.
  - `runtime.runShader(key, w, h, glsl, textures, uniforms)` -> Native OpenGL ES 3.0 fragment shader runner.
  - `runtime.detectBoxes(media, t)` -> MediaPipe EfficientDet-Lite0 box detector.
  - `runtime.getMediaPipeMask(media, w, h)` -> MediaPipe DeepLab-v3 + Selfie Multiclass human mask.
  - `runtime.getSamMask(media, w, h, opts)` -> EdgeSAM ONNX mask runner.
  - `runtime.chromaKey(media, w, h, targetRGB, tolerance, feather)` -> GPU or CPU green-screen removal.
  - `runtime.extractAudio(clip)` / `runtime.setAudioBuffer(buf)` -> PCM audio bridge.
- The QuickJS engine executes `init(clips)` once, then calls `renderFrame(ctx, width, height, t, duration, clips)` for every timeline tick.

--------------------------------------------------------------------------------
8. TWO-STEP BLIND VISUAL QA & SELF-HEALING ARCHITECTURE
--------------------------------------------------------------------------------
When enabled (or triggered manually via "AI Auto-Fix"):
1. The app renders a 25-frame output storyboard, a side-by-side [REF t | OUT t] comparison sheet, and an encoded preview MP4.
2. Step A (Blind Inspection): Sends the visual media to Gemini WITHOUT showing the existing code. Gemini scores 5 criteria (Aspect, Layout, Effects, Timing, Color) from 1 to 10 and reports visual defects.
3. Step B (Code Rewrite): If score < 8 or any sub-score fails, the diagnostic report, user media summaries, and existing code are sent to Gemini to rewrite `renderFrame()` and fix defects.
4. Technical Compile Verification: The rewritten code is tested across probe timestamps. If any runtime error or flat/blank frame is detected, it auto-repairs up to 6 times.
