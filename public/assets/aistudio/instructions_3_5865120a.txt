1. VISION SYSTEM ARCHITECTURE: 5-MODEL COOPERATIVE WORKFLOW
--------------------------------------------------------------------------------
The application bundles 5 pre-packed models in 'app/src/main/assets/' operating as two
cooperating visual tiers. You must design the vision manager to coordinate them without
any human touch, clicks, or manual bounding box drawing:

TIER 1: FAST ALL-PEOPLE ENGINE (MediaPipe Tasks Vision)
- Model 1: 'deeplab_v3.tflite' (~2.8 MB)
  * Functional Role: Global scene semantic segmentation.
  * Extraction Logic: Target Class Index 15 ('person'). Extracts silhouettes of all humans
    in the scene regardless of pose, orientation (facing front, side, or completely backward),
    distance, or crowd density.
- Model 2: 'selfie_multiclass_256x256.tflite' (~15.6 MB)
  * Functional Role: High-resolution human feature boundary refinement.
  * Extraction Logic: Invert Class Index 0 ('background') to yield confidence values for
    hair, facial skin, body skin, and clothing.
- Fusion Algorithm: Combine masks on a per-pixel basis using max(deeplabConf, multiclassConf).
  This eliminates selfie-model clipping on backward-turned people while maintaining sharp
  hair and shoulder boundaries. Execution must average 20–30 ms on GPU delegate.

TIER 2: ZERO-CLICK AUTO-DETECTION & PROMPTABLE HD CUTOUT (EdgeSAM + MediaPipe Detector)
- Model 3: 'efficientdet_lite0.tflite' (~4.4 MB)
  * Functional Role: Automated 0-click spatial coordinator.
  * Execution: Runs object detection across 80 COCO categories ('person', 'car', 'dog',
    'cat', 'motorcycle', 'bicycle', 'bottle', etc.). Automatically outputs normalized
    bounding boxes [ymin, xmin, ymax, xmax] without user taps.
- Model 4: 'edge_sam_3x_encoder.onnx' (~22.1 MB)
  * Functional Role: Image feature transformer.
  * Execution: Resizes input frame to 1024x1024, normalizes with ImageNet mean/std, and
    computes image embeddings of shape [1, 256, 64, 64]. Runs once per target frame.
- Model 5: 'edge_sam_3x_decoder.onnx' (~15.9 MB)
  * Functional Role: High-precision boundary extractor.
  * Zero-Click Handoff: Consumes the image embedding AND the bounding box generated by
    Model 3 (or the bounding box provided by Gemini). Maps box coordinates to 1024-space
    with prompt labels 2.0 (top-left) and 3.0 (bottom-right). Produces sub-pixel alpha
    masks for non-human objects, complex props, or isolated individuals in crowds.

MEMORY & EXECUTION REQUIREMENTS:
- MediaPipe models must load directly from assets via 'setModelAssetPath' using GPU delegate.
- ONNX models must be copied from assets to internal storage ('context.filesDir') on initial
  launch so ONNX Runtime can memory-map (mmap) them directly from disk, preventing Java heap spikes.
- ONNX sessions must enable NNAPI hardware acceleration when supported by the device chipset.

2. NATIVE RUNTIME API SPECIFICATION (QUICKJS JAVASCRIPT BRIDGE)
--------------------------------------------------------------------------------
The QuickJS engine must execute Gemini-synthesized JavaScript code by exposing an injected
host object named 'runtime'. You must implement the following raw native bridge methods:

1. Canvas & Frame Primitives:
   - runtime.getCanvas(key, width, height): Returns an isolated offscreen Bitmap/Canvas buffer.
   - runtime.getFrame(mediaIndex, timestampSec): Seeks the video or image at mediaIndex and
     returns a readable Bitmap snapshot.
   - runtime.drawCover(ctx, sourceMedia, x, y, width, height, zoom): Draws the source media
     into target rectangle [x, y, width, height] using aspect-fill cropping (no distortion).

2. GPU Shader Runner:
   - runtime.runShader(key, outWidth, outHeight, fragmentGlsl, texturesMap, uniformsMap):
     Compiles and runs arbitrary GLSL #version 300 es fragment shaders on an offscreen
     OpenGL ES 3.0 Framebuffer Object (FBO). Binds textures (Bitmaps) and uniforms (floats,
     vec2, vec3, vec4, ints, matrices). Returns rendered Bitmap for 2D compositing.

3. Zero-Click Detection & Segmentation Primitives:
   - runtime.detectBoxes(mediaIndex, timestampSec): Runs EfficientDet-Lite0 on the frame at
     timestampSec. Returns a JavaScript array of objects: [{ label: string, score: number,
     box: [x, y, w, h] }] with normalized 0..1 coordinates.
   - runtime.getMediaPipeMask(mediaIndex, width, height): Executes the dual MediaPipe
     pipeline (Models 1 + 2) and returns an object containing { width, height, data },
     where data is a Float32Array of 0.0..1.0 confidence values for all humans.
   - runtime.segmentMediaPipe(mediaIndex, width, height, featherOrOpts): Returns a transparent
     cutout Bitmap of all humans using the MediaPipe confidence mask.
   - runtime.getSamMask(mediaIndex, width, height, promptOpts): Executes EdgeSAM using
     promptOpts containing normalized boxes or points. Returns { width, height, data }
     with Float32Array confidence values.
   - runtime.segmentSam(mediaIndex, width, height, promptOpts, featherOrOpts): Returns a
     transparent cutout Bitmap of the exact prompted object or subject.

4. Audio Primitives:
   - runtime.extractAudio(clipIndex): Retrieves pre-decoded PCM AudioBuffer from user video.
   - runtime.setAudioBuffer(audioBuffer): Registers active audio track for playback/export.

EXECUTION CONTRACT RULES FOR JAVASCRIPT:
- Code must declare 'async function init(clips)' and 'async function renderFrame(ctx, width, height, t, duration, clips)'.
- Top-level variables must hold state between frames; 'init' must not return an object.
- Drawing must occur directly onto the passed 'ctx'; functions must not return a canvas.
- All coordinate, dimension, line width, and font math must scale proportionally from (width, height).
- Masking or tinting operations using 'source-in' or 'destination-in' MUST execute on an isolated
  canvas obtained via 'runtime.getCanvas()' to avoid clearing the background layer.

4. ENGINE SELECTION RULES (ACROSS ALL 4 APPLICATION MODES)
--------------------------------------------------------------------------------
Gemini must be instructed in Stage 1, Stage 2, and Stage 3 prompts on how to automatically
select between MediaPipe and EdgeSAM across all operational modes:

SELECTION CRITERIA DIRECTIVE:
1. Choose MediaPipe ('runtime.segmentMediaPipe' / 'runtime.getMediaPipeMask') when:
   - The cutout target is human (front view, back view, profile, dancers, crowds).
   - Fast real-time multi-person segmentation or depth-behind-people is required.
   - No external non-human accessories need to remain attached to the subject.
2. Choose EdgeSAM ('runtime.detectBoxes' + 'runtime.segmentSam' / 'runtime.getSamMask') when:
   - The cutout target is NON-HUMAN (cars, motorcycles, pianos, guitars, pets, shoes, anime characters).
   - The scene contains multiple people, but ONLY ONE specific individual must be isolated.
   - A person is holding a complex accessory (guitar, skateboard, handbag) that MediaPipe would clip.
   - Edge refinement is required for fine curly hair or transparent clothing.

MODE-SPECIFIC EXECUTION SPECIFICATIONS:

Mode A: Reference Video + User Media + Prompt
- Stage 1 analyzes reference mechanics and records 'maskEngine: mediapipe | edgesam' in blueprint JSON.
- Stage 2 evaluates user prompt against reference blueprint. If user prompt specifies a non-human
  object or isolated subject, it overrides Stage 1 and invokes EdgeSAM with live box coordinates.

Mode B: Reference Video + User Media (NO User Prompt)
- Stage 1 watches the reference video cut sheet. If the reference isolates a vehicle, prop, or
  specific subject, it sets 'maskEngine: edgesam'. If it isolates dancers/people, it sets 'maskEngine: mediapipe'.
- Stage 2 visually matches user clips against the reference roles and binds the corresponding engine.

Mode C: User Media + Prompt (NO Reference Video)
- Gemini reads prompt text and inspects user media contact sheets.
- If the prompt targets vehicles, pets, instruments, or anime, Gemini generates code calling
  'runtime.detectBoxes()' and passes the detected box to 'runtime.segmentSam()'.
- If the prompt targets human subjects, Gemini generates code calling 'runtime.segmentMediaPipe()'.

Mode D: User Media ONLY (NO Reference Video & NO User Prompt)
- Gemini visually analyzes the uploaded media contact sheets (clipIndex 0..N).
- If the visual subject in Clip 0 is a vehicle, animal, or product, Gemini automatically applies
  EdgeSAM using 'runtime.detectBoxes()'.
- If the visual subject in Clip 0 is human, Gemini automatically applies MediaPipe.
- Vertex AI First-Pass Guarantee: Because Visual QA is unchecked by default on Vertex AI, Gemini
  must log its chosen engine and execute the correct engine on the very first generation pass.

5. TWO-STEP BLIND VISUAL QA & SELF-HEALING CONTRACTS
--------------------------------------------------------------------------------
When Visual QA executes (or when user clicks 'AI Auto-Fix'), enforce this two-step audit protocol:

STEP A: BLIND VISUAL AUDIT CONTRACT
- Input Media sent to Gemini:

  2. Side-by-side comparison sheet [REF t | OUT t] (if available).
  3. Rendered 25-frame output storyboard of the current edit.
  4. Encoded output preview MP4 video.
  5. User prompt and revision notes (if any).

- Audit Prompt Requirement:
  Instruct Gemini to inspect visual playback and rate five criteria from 1 to 10:
  * Aspect & Framing (check for stretched/squashed faces in panels; cover-cropping verification).
  * Layout & Geometry (panel proportions, borderless seams vs unwanted lines).
  * Effects & Polish (motion blurs, multi-strand light wisps with additive blending, flares).
  * Timing & Cuts (synchronization with beat peaks and scene cut timestamps).
  * Color & Mood (contrast, cinematic grading, transition fades).
- Expected Response: Emits '===JSON_RESULT===' with:
  {
    "passed": boolean,
    "score1to10": number,
    "aspectAndFraming1to10": number,
    "layoutAndGeometry1to10": number,
    "effectsAndPolish1to10": number,
    "timingAndCuts1to10": number,
    "colorAndMood1to10": number,
    "visualObservations": string,

STEP B: CODE REWRITE CONTRACT

  2. Clip summaries (dimensions, duration, audio presence).
  3. Reference blueprint and Stage 1 tools code.
  4. Current failing pipeline JavaScript code.
- Rewrite Instructions:
  - Stream '[LOG]' entries explaining how every visual defect is corrected.
  - Fix squashed panels by replacing raw drawImage with 'runtime.drawCover()'.
  - Switch segmentation engine if MediaPipe clipped accessories or failed on non-humans (switch to 'detectBoxes' + 'segmentSam').
  - Ensure all masking operations run on an isolated offscreen canvas via 'runtime.getCanvas()'.
  - Output '===JSON_RESULT===' containing updated duration and aspect ratio.
  - Output '===CODE_RESULT===' containing the complete corrected JavaScript code.

TECHNICAL VALIDATION LOOP:
- The native host compiles rewritten code in QuickJS and test-renders across 9–14 probe timestamps.
- If an execution exception occurs or output frames measure >96% flat single-color, the host sends
